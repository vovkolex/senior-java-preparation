1. Add new concepts/questions to the relevant topic file.
2. Preserve important mistakes and interview traps.
3. Add an interview-ready English answer for high-value questions.
4. Add ASCII schemas/flows when they make architecture or runtime behavior clearer.
5. Avoid duplicating material already present.
6. Prefer concise revision notes over long textbook explanations.
